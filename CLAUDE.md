# Project Instructions

For all landing page development tasks, always read and follow:

`.skills/landing-architecture/SKILL.md`

The rules in that skill are mandatory for:

- technology stack
- project architecture
- vertical slicing
- file organization
- responsive implementation
- Tailwind usage
- TypeScript conventions
- Astro component structure
- client-side JavaScript usage
- performance decisions

If there is a conflict between general project conventions and `.skills/landing-architecture/SKILL.md`, follow the skill unless the user explicitly requests otherwise.

## Development

When starting the dev server, use background mode:

```bash
astro dev --background
```

Manage the background server with:

```bash
astro dev stop
astro dev status
astro dev logs
```
